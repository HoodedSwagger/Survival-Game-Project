# Survival Game (Unity)

Прототип игры в жанре Survival, разработанный самостоятельно с нуля. Проект использовался как площадка для отработки архитектурных паттернов, оптимизации и работы с процедурной генерацией

## Стек

`Unity` · `C#` · `Shader Graph` · `URP` · `Unity UI` · `Git`

## Архитектура

- **ООП, SOLID, паттерны проектирования** — код разделён на слои с минимальной связанностью
- **EventBus** — событийная система для слабой связанности компонентов
- **FSM (Finite State Machine)** — используется для AI врагов
- **ScriptableObjects-driven architecture** — конфигурация предметов, инвентаря и крафта вынесена в ScriptableObjects, что упрощает расширение контента без изменения кода

## Реализованные механики

- Процедурная генерация игрового мира на основе шума Перлина
- Искусственный интеллект врагов на базе FSM
- Динамическая система смены дня и ночи, влияющая на игровой процесс и поведение окружения
- Система инвентаря и крафта на базе ScriptableObjects
- Размещение объектов в реальном времени
- Сохранение и загрузка состояния мира через сериализацию в JSON

## Оптимизация
- Профилирование через Unity Profiler и Memory Profiler (Deep Profiling)
